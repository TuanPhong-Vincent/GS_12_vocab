# Vocab & Exercises HTML Preview Skill (`vocab_preview`)

## Role & Purpose

You are a digital curriculum engineer and educational UI specialist. Your mission is to generate a comprehensive, modern, standalone HTML preview file for any Unit's vocabulary (`vocab.json`) and practice exercises (`exercises/*.json`), allowing teachers, curriculum quality reviewers, and students to inspect, audit, or practice the lesson content directly in their browser without running any web server.

---

## When to Use This Skill

Activate this skill when:
- The user asks to preview or create an HTML viewer/preview for a Unit's vocabulary folder (e.g. `data/gs-6/unit-7/vocab`).
- The user wants an intuitive visual report of `vocab.json` and all practice exercises generated by `data-vocab-step-7-practice`.
- The user references "vocab_preview", "preview vocab", "tạo file html xem từ vựng", or "hiển thị bài tập dạng html".

---

## Target Inputs

The skill requires:
- **Target Vocab Directory**: Absolute or relative path to the Unit's `vocab/` directory (e.g., `d:/demo_lesson_data/data/gs-6/unit-7/vocab`).
- Expected files in the directory:
  - `vocab.json`: Vocabulary items structured with groups, phonetic transcriptions (UK/US), Vietnamese meanings, example sentences, audio paths, and image paths.
  - `exercises/` subfolder: JSON exercise files (e.g., `01_multiple_choice_direct.json` through `16_translate_sentences.json`).

---

## Execution Workflow

### Step 1: Validate Inputs
Verify that the target directory exists and contains `vocab.json` and/or the `exercises/` folder:
```powershell
Test-Path "<path_to_vocab_folder>"
```

### Step 2: Run the Preview Generator Script
Execute the bundled Python script:
```powershell
python .agent/skills/skills-vocab-preview/scripts/generate_vocab_preview.py "<path_to_vocab_folder>"
```

Options:
- `--output` or `-o`: Custom destination path for the HTML file (defaults to `<path_to_vocab_folder>/vocab_preview.html`).

*Example:*
```powershell
python .agent/skills/skills-vocab-preview/scripts/generate_vocab_preview.py d:\demo_lesson_data\data\gs-6\unit-7\vocab
```

### Step 3: Verify Output
Check that `vocab_preview.html` was created and report statistics:
- Total words and categories/groups.
- Total exercise types detected and total question count.
- Clickable link to open the HTML file: `file:///<path_to_vocab_folder>/vocab_preview.html`.

## Key Features of the Generated HTML

1. **Standalone & Zero-Dependency**:
   - 100% self-contained single HTML file (CSS and JS are embedded inline).
   - Works completely offline without needing an active web server or internet connection.
   
2. **Modern & Elegant Design**:
   - Clean, publication-grade typography and balanced spacing.
   - High-contrast visual hierarchy with Indigo/Emerald/Slate color schemes.
   - Fully responsive for desktop, tablet, and mobile screens.

3. **Dual Interactive Modes**:
   - **Review Mode (Xem Đáp Án)**: Displays correct answers immediately with green checkmarks, highlighted radio options, and pre-filled blanks. Ideal for curriculum audits, QA, and teachers.
   - **Practice Mode (Làm Bài)**: Clears blanks and unselects radios. Reviewers or students can click choices, fill in answers, and click **"Kiểm Tra Đáp Án"** to calculate instant scores and see color-coded feedback.

4. **Speech & Audio Integration**:
   - Built-in **Web Speech API** text-to-speech button (`🔊`) next to each vocabulary word and example sentence. Speaks standard British/American English natively in any modern browser without requiring audio server hosting.

5. **Tailored Renderers for All 16 Exercise Types**:
   - **01, 02, 03 (Multiple Choice)**: Direct, Sentence Completion, and Conversation dialogue bubbles.
   - **04 (Pic to Word)**: Image card with fallback placeholder, input blank, and answer key badge.
   - **05 (Write English Words)**: Two-part questions with Vietnamese prompts and English input blanks.
   - **06 (Fill in Blanks)**: Tag cloud Word Box with sentence blank inputs.
   - **07 (Paragraph Fill)**: Cohesive reading passage with inline numbered input slots.
   - **08 (Sentence Ordering)**: Sentences a-d pills, ordering choices, and full reconstructed paragraph preview.
   - **09, 10 (Closest & Opposite Meaning)**: Distinct underlined highlight for target words `[...]`.
   - **11 (Dictionary Entry)**: Oxford-style dictionary cards with definition, bold collocations, and contextual questions.
   - **12 (Signs and Notices)**: Visual sign board preview box with descriptive prompt, question stem, and 4 choices.
   - **13 (Word Families Table)**: Clean matrix table of Base Word, Verb, Noun, Adjective, and Adverb.
   - **14 (Word Families MCQ)**: Contextual derivation multiple choice questions.
   - **15 (Word Formation)**: Sentences with uppercase root word badge `[ROOT]`.
   - **16 (Translate Sentences)**: Vietnamese prompt sentences with translation reveal/check input.

6. **Instant Search**:
   - Real-time search bar at the top instantly filters vocabulary words and exercise questions as the user types.

7. **Print / PDF Friendly**:
   - Integrated CSS `@media print` rules remove headers, navigation bars, and buttons to format clean printable worksheets.
